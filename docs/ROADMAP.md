# StoreMind AI 研发路线图

## M0：开发基线与安全（P0）
- [ ] 上传并校验完整 MVP 源码
- [ ] 配置自动化测试和依赖扫描
- [ ] 完善企业 / 门店数据隔离与越权测试
- [ ] 生产环境移除演示账号及默认密钥
- [ ] 引入 Alembic 数据库迁移、备份和恢复

验收：Windows 新手可按 README 启动，测试全部通过，跨租户访问被拒绝。

## M1：真实经营闭环（P0）
- [ ] POS CSV 导入与订单去重
- [ ] 门店销售、退款和对账
- [ ] 库存流水、损耗和安全库存
- [ ] 补货建议与采购审批
- [ ] 员工排班日历和需求预测
- [ ] 任务提醒和执行记录

验收：一家真实试点门店能导入订单、对账、分析经营情况并完成补货审批。

## M2：连锁协同（P1）
- [ ] 企业开户、门店创建、员工邀请和角色授权
- [ ] 总部 / 区域 / 门店经营分析
- [ ] SOP 文档知识库与来源引用
- [ ] AI 日报、周报和异常提醒
- [ ] 总部支持工单与处理进度

验收：3–30 家门店可按授权范围协同管理。

## M3：商业化 SaaS（P1）
- [ ] 套餐与订阅计费
- [ ] 监控、告警和操作审计
- [ ] 数据导出、删除和备份恢复
- [ ] 安全测试与隐私合规
- [ ] 灰度发布和故障回滚

## M4：视觉和 IoT（第二阶段）
- [ ] 摄像头事件接入与人工复核
- [ ] 设备身份、MQTT、温度采集
- [ ] 异常事件、告警与维修工单
- [ ] 数据最小化与合规审查

原则：AI 只能基于授权业务数据提出建议；采购、排班变更、库存调整等重要操作必须经过授权人员确认。
